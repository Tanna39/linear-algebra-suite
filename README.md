# Numerical Methods Project — Linear Algebra Suite

An interactive web-based **Numerical Methods Project** designed for solving linear algebra problems, analyzing iterative convergence, and performing curve fitting using different numerical techniques.

## 📌 Project Overview

**Linear Algebra Suite** is an interactive computational tool that brings several important numerical methods into a single web interface. Users can enter matrix systems, select a numerical method, calculate solutions, view step-by-step execution logs, analyze convergence behavior, and perform regression-based curve fitting.

The project is developed using **HTML, CSS, and JavaScript** with Tailwind CSS and Chart.js for the user interface and data visualization.

## 🚀 Features

### 🧮 Matrix Solvers Engine

The project supports the following matrix-solving methods:

* **Gauss Elimination with Partial Pivoting**
* **LU Decomposition — Doolittle Method**
* **Matrix Inverse — Gauss-Jordan Method**
* **Cramer's Rule**
* **Gauss-Seidel Iteration**
* **Jacobi Iteration**

Additional matrix analysis includes:

* Determinant calculation
* Singular / non-singular matrix detection
* Diagonal dominance checking
* Step-by-step computational logs
* Matrix inverse visualization
* Solution vector display

### 📈 Iteration Convergence Analytics

The project provides convergence analysis for iterative methods.

Supported methods:

* Gauss-Seidel
* Jacobi

The system records iteration errors and visualizes the convergence behavior using an interactive chart.

### 📉 Curve Fitter Canvas

The Curve Fitter module supports:

* **Linear Least Squares Regression**
* **Quadratic Polynomial Regression**
* **Exponential Regression**

It also provides:

* Regression equation
* Data point visualization
* Regression curve visualization
* Coefficient of Determination (**R²**)
* Standard error calculation

## ▶️ How to Run

No installation or build process is required.

### Option 1 — Run Locally

1. Download or clone the repository.
2. Keep all project files in the same folder.
3. Open `index.html` in a modern web browser.
4. Select a numerical method and enter the required values.
5. Click the corresponding calculation button to view the results.

### Option 2 — GitHub Pages

The project can be hosted using **GitHub Pages**.

After enabling GitHub Pages for the repository, the application can be accessed directly through the generated GitHub Pages URL.
